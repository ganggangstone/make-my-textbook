# make-my-textbook

[English](./README.en.md)

![make-my-textbook](./docs/banner.png)

**AI 시대, 나를 위한 맞춤형 전공 교재를 만든다.** 코드나 논문을 알려주면 지금 내 수준에 맞춰 공부용 교재로 써 준다. 문장마다 "원문에 있는 말인지, 통설인지, 추론인지"를 표시하고 원문을 인용한 곳에는 각주를 달아서, 어디서 나온 말인지 직접 확인할 수 있다.

시각디자인을 전공한 비개발자가 AI로 코딩을 배우다가 내 눈높이에 맞는 교재를 찾지 못해서 만든, Claude Code용 작업 지침 파일(스킬)이다.

## 결과물

![예제 교재를 넘겨 보는 화면](./docs/demo-ko.gif)

`examples/self-attention/`을 이 스킬로 만든 결과다. 논문 한 편의 한 절로 만든 1장짜리 교재이고, PDF로 볼 수 있다: [한국어](./examples/self-attention/self-attention.ko.pdf) · [English](./examples/self-attention/self-attention.en.pdf)

문장마다 붙는 표시는 이렇게 생겼다(한 문단을 원래 크기로 자른 것).

![근거 등급 태그와 각주가 붙은 문단](./docs/proof-ko.png)

`[일반]`은 분야의 통설, `[확정]`은 원문에 그대로 있는 말, `[부재]`는 읽은 범위에서 찾지 못한 것이다. 오른쪽 위의 작은 숫자는 각주 번호다.

## 이 스킬로 만든 책

스킬을 다듬는 데 쓴 책 두 권의 쪽이다. 두 권 모두 이 저장소에는 들어 있지 않다.

**논문과 기술 문서로 만든 책.** 영상 생성 AI 모델을 처음부터 원문 논문 수준까지 다룬 477쪽짜리 책의 96~97쪽이다.

![논문과 기술 문서로 만든 책의 펼침면](./docs/book-paper.png)

**코드로 만든 책.** 백엔드 코드를 읽는 법을 다룬 책의 8장 앞부분이다. 실제 코드 파일 하나를 통째로 싣고 읽는 절차를 가르치는 쪽이다. 코드 예시의 프로젝트 이름은 바꿨다.

![코드로 만든 책의 펼침면](./docs/book-code.png)

## 이런 사람에게 맞다

기술 배경 없이 코드나 논문, 공식 문서를 이해해야 하는 사람이다. 예를 들어 AI가 짜 준 코드를 이해하고 싶은 비개발자, 처음 보는 논문을 읽어야 하는 사람이다. 글자는 읽히는데 무슨 말인지 모를 때 쓴다. 만들 때 Claude Code를 쓰므로 터미널이 아주 낯설지는 않아야 한다.

## 쓰는 법

1. 저장소를 스킬 폴더에 받는다: `git clone https://github.com/ganggangstone/make-my-textbook ~/.claude/skills/make-my-textbook`
2. Claude Code에서 `/source-grounded-textbook`을 입력한다. Claude가 알아서 켜지 않으니 직접 입력해야 시작된다. 명령이 안 보이면 `/`를 눌러 목록에서 이 스킬을 찾는다.
3. Claude가 묻는 질문에 답한다(무슨 자료로 공부할지, 지금 무엇을 아는지, 어디까지 이해하고 싶은지). "빠르게 시작"을 고르면 이 네 가지만 묻고 나머지는 기본값을 보여 준다. 답에 맞춰 Markdown(메모장으로도 고칠 수 있는 텍스트 파일) 원고가 나온다.
4. PDF가 필요하면 그렇게 말한다. Node.js 22.12 이상과 인터넷 연결이 필요하다. 폰트를 받고, 처음 한 번은 브라우저도 받는다.

영어로 쓰려면 받은 폴더에서 `cp SKILL.en.md SKILL.md`를 실행한다. Claude Code는 `SKILL.md`라는 이름의 파일만 읽는다.

## 챗봇에게 그냥 물어보는 것과 다른 점

- **출처를 대조할 수 있다.** 문장마다 원문에 있는 말, 통설, 추론, 자료에서 못 찾은 것을 구분해서 표시한다. 시작할 때 이 표시를 끌 수도 있다.
- **내 수준에서 시작한다.** 쓰기 전에 지금 아는 것과 목표를 묻고, 새 개념은 한 절에 하나씩만 나온다. 이 한도도 바꿀 수 있다.
- **다 쓴 뒤 다시 읽고 고친다.** 정의 없이 쓴 낱말, 원문과 다르게 옮긴 문장, 건너뛴 단계를 찾는 순서가 스킬에 적혀 있다.
- **원고가 Markdown 파일이라 직접 고치고 다시 PDF로 만들 수 있다.**

## 지금 한계

- 초안이다. 써 본 사람은 만든 사람 한 명뿐이다.
- 이 저장소에서 다시 만들어 볼 수 있는 예제는 논문 한 편의 한 절뿐이다. 코드로 만든 예제는 위 책의 쪽만 있다.
- 시작할 때 묻는 질문이 자세히 정하면 13개, 빠른 경로로 시작하면 4개다. 빠른 경로는 아직 실제 대화로 시험하지 못했다.
- 설치와 실행 방법은 다른 사람의 컴퓨터에서 아직 시험하지 못했다.

## 구성

- [`SKILL.md`](./SKILL.md): 스킬 본문. 한국어판이 기준이다.
- [`pipeline/`](./pipeline/): 원고를 PDF로 만드는 도구. 포인트 색을 고를 수 있다.
- [`examples/self-attention/`](./examples/self-attention/): 시작할 때 한 질문의 답, 원고, 결과 PDF.

## 언어

영어판 `SKILL.en.md`는 같은 내용을 영어권 자습서 방식으로 새로 쓴 글이다. 규칙을 바꿀 땐 한국어부터 고치고 영어판을 맞춘다. 한국어 원고와 영어 원고를 모두 PDF로 만들 수 있고, 언어별 차이는 [`pipeline/README.md`](./pipeline/README.md)에 있다.

다른 언어로 쓰고 싶으면 Claude에게 그 언어로 쓰라고 하면 된다. PDF에 필요한 언어 설정 파일은 스킬이 시키는 대로 Claude가 영어 설정 파일을 복사해 만든다. 한국어 원고는 stop-slop-ko 스킬로 AI 말투를 한 번 더 걷어낸다. 설치돼 있지 않으면 스킬이 그 지침을 GitHub에서 받아 쓴다.

**시험한 언어는 한국어와 영어뿐이다.** 스페인어·프랑스어·독일어처럼 라틴 문자를 쓰는 언어는 영어 설정 파일(`pipeline/lang/en.mjs`)을 복사해 문구만 바꾸면 될 것으로 보지만 돌려 보지 않았다. 일본어·중국어·아랍어는 줄바꿈 규칙, 폰트, 글자 방향이 달라서 프로필 외에 CSS를 더 손봐야 할 수 있고, 이 저장소는 그 부분을 지원하지 않는다.
