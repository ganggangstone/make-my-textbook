# 시작할 때 받은 질문과 답 (이 예제용)

SKILL.md의 Step 0 질문에 이 예제를 위해 답한 값. 실전에서는 사용자에게 직접 물어야 하고,
여기서는 예제를 만들기 위해 임의로 정했다.

1. **자료 종류**: 논문(단일 편).
2. **자료 범위**: Vaswani et al., "Attention Is All You Need" (arXiv:1706.03762), 초록과
   3.2.1절("Scaled Dot-Product Attention")과 그 절의 각주 4만.
3. **독자 출발점**: 고등학교 수준 수학(벡터·행렬 곱, 지수함수)까지. 딥러닝 배경 없음.
4. **목표 이해 수준**: `softmax(QKᵀ/√d_k)V` 수식이 각 기호마다 무엇을 계산하는지 한 단계씩
   설명할 수 있는 수준.
5. **최종 목적**: 이 수식 하나(Scaled Dot-Product Attention)의 완전한 이해. 분야 전반이 아님.
6. **설명 방식 비중**: 그림 없음(1장짜리 예제라 생략). "왜" 설명은 개념마다 한두 문장.
7. **암기 대 이해**: 이해 위주. 기호 표기(Q, K, V, d_k)는 외워야 하는 표기 규칙으로 명시.
8. **근거 등급 체계**: 사용.
9. **원문 처리**: 원문 그대로 인용 + 역: 캡션.
10. **연습 형식**: 개념마다 즉석 확인(답은 문제 바로 뒤), 장 끝 연습 1개 + 복습 3문항(해답은 책 맨 뒤
    부록 A). 화면 매체이므로 답 쓸 칸은 생략.
11. **분량 제약**: 데모 목적, 1장만.
12. **문체·구성 기본값**: 기본값 그대로.
13. **결과물 형식**: 마크다운 원고 + 빌드 도구로 만든 PDF(기본값).
